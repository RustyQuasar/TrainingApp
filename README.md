# Training App - SCOUTING LEAD Message

Hello, this app was designed for new scouting recruits to learn without being directly thrown into a scouting app. The premise is a basic calculator; with a number pad, a decimal button, a positive/negative switch, and the following operation buttons: Power of, Divide, Multiply, Add, Subtract.

This is the branch intended to train Java new recruits, with both Sample.java and CalculatorActivity.java being located in ../app/src/main/java/scouting/training

Because java cannot be standalone without UI, I have also made UI layout files located in ../app/src/main/res/layout
